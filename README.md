# プライバシーポリシー

本アプリケーション（以下「当アプリ」）における利用者情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

## 1. 取得する情報および利用目的
当アプリでは、サービスの提供・改善および広告配信のために以下の情報を取得・利用する場合があります。

- **広告配信に関する情報**:
  当アプリでは、第三者配信事業者（Google AdMob）による広告を掲載しています。広告配信事業者は、利用者に適した広告を表示するためにCookieや端末識別子等の情報を収集・利用する場合があります。詳細は Googleのプライバシーポリシーをご確認ください。
- **AI鑑定機能の利用に関する情報**:
  当アプリの占い結果生成機能において、ユーザーが入力した相談内容や質問テキストをAIサービス（Google Gemini API）に送信します。これらのデータは占い結果の生成のみに利用され、個人を特定する目的や開発者による不当な利用は行いません。

## 2. 個人情報の第三者提供
当アプリは、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供することはありません。

## 3. 免責事項
当アプリの鑑定結果や提供する情報について、その正確性や将来の出来事を保証するものではありません。当アプリの利用によって生じた損害やトラブル等について、開発者は一切の責任を負いかねますのであらかじめご了承ください。

## 4. プライバシーポリシーの変更
本ポリシーの内容は、法令の改正やサービスの改善に伴い、事前の予告なく変更することがあります。

## 5. お問い合わせ
本ポリシーに関するお問い合わせは、ストア掲載の開発者連絡先よりお願いいたします。
